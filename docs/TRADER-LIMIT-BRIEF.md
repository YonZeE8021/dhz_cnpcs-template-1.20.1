# 商人限购与库存变量（精简版）

给**服主**和**做 NPC 的人**看的短说明，不讲代码。

---

## 这是干什么的？

在商人（Trader）角色上，可以给每一行交易单独配置：

1. **玩家限购** — 每个玩家能买几次、多久刷新  
2. **商人库存变量** — 用数字变量表示「还剩多少货」，买一笔就加减，可定时补货  

两者可以单独用，也可以一起用。

---

## 在哪里设置？

1. 用魔杖打开 NPC → 角色选 **商人**  
2. 主界面右侧：**商人库存变量**（定义变量）  
3. 每一行交易右侧小按钮（显示 **不 / 终 / 现 / 游 / 在**）→ 该行限购与变量操作  

保存 NPC 后生效；若填了 **市场名称**，同名市场的商人会共用全局变量。

---

## 商人库存变量（要点）

| 项 | 说明 |
|---|---|
| **变量名** | 普通名 = 仅本 NPC；以 `global.` 开头 = 全服/市场共用 |
| **初始值** | 开档或重置后的数量 |
| **最大值** | `-1` 表示无限；有上限时玩家会看到 `当前/上限` |
| **重置周期** | 不重置 / 现实时间 / 游戏时间 → 到点补回初始值 |
| **玩家可见** | 勾选后，买家悬停商品能看到库存与补货倒计时 |

在某一行的限购界面里，可配置 **购买时变量操作**（变量名 + 增减，常见为 `-1` 表示卖出一单减 1）。

---

## 玩家限购（五种）

主界面小按钮上的字对应该行策略：

| 字 | 含义 |
|---|---|
| **不** | 不限购 |
| **终** | 终身只能买 N 次 |
| **现** | 按现实时间周期刷新次数 |
| **游** | 按世界游戏时间周期刷新 |
| **在** | 按玩家在线时间周期刷新（离线不计） |

---

## 玩家买东西时看到什么？

悬停**售出物品格**时：

- 底部一行状态：**货币充足** / **货币不足** / **已达交易上限** / **商人缺货** / **商人库存已满**  
- 上方提示框分区显示：  
  - **【限购】** 还可购买几次、限购何时刷新  
  - **【商人库存】** 可见变量的当前库存（有上限为 `n/m`）、补货时间  

信息约 **每秒** 向服务器刷新一次；倒计时在两次同步之间会本地走动。

---

## 三种「不能买」别搞混

| 提示 | 常见原因 |
|---|---|
| **已达交易上限** | 玩家自己的限购次数用完了 |
| **商人缺货** | 库存变量不够减（例如剩 0 还要再卖） |
| **商人库存已满** | 有上限的变量已满，本次购买会超出上限 |

---

## 给服主的实用建议

- 只限「每人买几次」→ 只配 **玩家限购**，不必建变量  
- 全服共卖 100 个 → 建 `global.xxx` 变量，多商人填**同一市场名**  
- 每 NPC 独立库存 → 用**本地变量名**（不要 `global.` 前缀）  
- 想让玩家看见剩余 → 记得勾 **玩家可见**，并在该行挂上对应变量操作
